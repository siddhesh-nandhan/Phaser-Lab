03 Transition code

How to paste your own transition

Use async function transition({ canvas, ctx, from, to, width, height, options }). The images are already loaded. Options include duration, origin, hexSize and colors. A goToScene(scene, key, data, options) function is also supported through a small scene adapter, including the function from this chat. The adapter exposes scene switching, render events and the canvas; it is not the full Phaser engine. External imports and PhaserFX calls need their libraries and are not included. Press Play to run your edited code. Reset also stops a running effect.

For a custom canvas effect, call drawImage(to, 0, 0, width, height) to draw the next screen. Code runs in a separate preview frame. No screenshots are uploaded to a server.

02 Button effect code

How button code works

Define function buttonEffect(button, options). The button is a real HTML button. Options contain clickScale and duration. Return an object with a stop() method for cleanup. Press Apply code after editing. This preview recreates Button Juice without requiring Phaser; Phaser-specific code needs the Phaser engine.
